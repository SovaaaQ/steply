# Материалы для отчета по практике

## 1. Описание выполненной работы

В рамках работы над выпускной квалификационной работой была выполнена доработка веб-приложения Steply, предназначенного для поддержки формирования поведенческих привычек на основе анализа активности пользователя. Основное внимание было уделено повышению демонстрационной готовности проекта, улучшению структуры frontend-части, обновлению пользовательского интерфейса и подготовке понятных инструкций по запуску приложения.

Была проведена реструктуризация frontend-части проекта. Точка входа приложения была упрощена, верхнеуровневая логика вынесена в отдельный модуль приложения, а пользовательский интерфейс разделен на страницы, layout-компоненты, переиспользуемые UI-блоки и доменные компоненты для привычек, статистики, рекомендаций и достижений. Работа с REST API была организована через отдельные сервисы, а типы данных и вспомогательные функции были вынесены в самостоятельные директории.

Также был обновлен визуальный стиль приложения под концепцию 2026 года. Интерфейс ушел от стерильного минимализма к более глубокому wellness/productivity-образу: теплый фон Cloud Dancer, контрастный Plum Noir, Transformative Teal для бренда и прогресса, точечный Wasabi для CTA и достижений, Persimmon для риска и восстановления, Icy Blue для аналитики и рекомендаций. Главный экран был оформлен как демонстрационная панель, на которой пользователь сразу видит прогресс дня, привычки на сегодня, уровень, серию, жизни, риск пропуска и рекомендацию дня.

Отдельно была проработана адаптивность интерфейса. Для desktop-версии используется боковая навигация, верхняя панель и сеточная компоновка ключевых блоков. Для mobile-версии подготовлена компактная структура с нижней навигацией, карточками в одну колонку, крупными кнопками и удобными отступами. Интерфейс был проверен на ширинах 390, 430, 768, 1024 и 1440 пикселей.

Для backend-части была уточнена конфигурация подключения к PostgreSQL, подготовлены переменные окружения и обновлен `docker-compose.yml` для локального запуска базы данных через Docker. В документацию были добавлены инструкции запуска backend, frontend, PostgreSQL через Docker, подключения к локальному PostgreSQL, проверки работоспособности API и демонстрационного сценария для защиты.

## 2. Описание архитектуры frontend

Frontend-часть приложения была разделена на несколько логических уровней. В директории `app` расположены верхнеуровневые элементы приложения: основной компонент, роутер и provider состояния. В директории `pages` находятся самостоятельные экраны приложения: главная панель, привычки, статистика, рекомендации, достижения, профиль, вход и регистрация.

Переиспользуемые компоненты вынесены в директорию `components`: layout-компоненты отвечают за каркас интерфейса, UI-компоненты используются для кнопок, карточек, полей ввода и состояний, а доменные компоненты отвечают за отображение привычек, статистики, рекомендаций и достижений. Работа с backend API организована в директории `services`, типы данных вынесены в `types`, пользовательские hooks — в `hooks`, а вспомогательные функции — в `utils`.

## 3. Описание дизайна

Дизайн-концепция Steply основана на идее постепенного движения к устойчивым привычкам маленькими шагами. Интерфейс построен по правилу 60/30/10: большую часть занимает теплый спокойный Cloud Dancer, около трети — карточки, muted teal-поверхности и Plum Noir-секции, а яркие Wasabi/Persimmon-акценты используются точечно для действий, риска, достижений и восстановления. Цвета связаны с UX-смыслом: teal показывает прогресс и спокойные акценты, Icy Blue — аналитику и подсказки, Wasabi — позитивное действие, Persimmon — риск пропуска.

Главный экран приложения спроектирован как рабочая панель пользователя. На нем размещены бренд Steply, выразительный hero-блок, прогресс дня, быстрые действия, список сегодняшних привычек, показатели серии, уровня, жизней, риск пропуска и персональная рекомендация. Для мобильной версии применена нижняя навигация, одноколоночная структура карточек и крупные интерактивные элементы, что делает приложение удобным на экране телефона.

## 4. Описание базы данных

Для хранения данных приложения используется PostgreSQL. В backend-части подключение к базе данных выполняется через SQLAlchemy и переменную окружения `DATABASE_URL`. Также предусмотрены отдельные переменные для имени базы, пользователя, пароля, хоста и порта, что упрощает настройку проекта на разных компьютерах.

Для локального развертывания базы данных подготовлен `docker-compose.yml`, который запускает контейнер PostgreSQL с нужными параметрами. Таблицы создаются автоматически при старте backend на основе SQLAlchemy-моделей. Такой подход удобен для дипломной демонстрации, так как позволяет быстро подготовить рабочее окружение без ручного создания схемы.

## 5. Описание результата

В результате выполненных работ проект Steply стал более структурированным, понятным и готовым к демонстрации. Frontend больше не сосредоточен в одном файле, интерфейс разделен на переиспользуемые компоненты, а работа с API, типами и вспомогательными функциями вынесена в отдельные модули.

Приложение получило современный адаптивный интерфейс, который корректно выглядит на desktop и mobile-экранах. Были подготовлены скриншоты основных разделов, обновлена документация и описан порядок запуска с PostgreSQL и Docker. Проект можно использовать как основу для демонстрации на защите ВКР и для описания проделанной работы в отчете по практике.
